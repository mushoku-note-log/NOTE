# LINEスタンプを作ろうとしたら、48時間たっても完成しません｜note収益化【27日目】

## 概要

27日目の報告。数字は全体ビュー3,386・スキ939・コメント19・フォロワー445人（前日比+52）・累計売上400円（新規売上0円）。クイーンのLINEスタンプ制作が48時間以上たっても完成しないと報告。キャラクターの不安定さ（前足が3本になる、毛色が変わる等）、アスペクト比・透過背景の指定不遵守、複数コマ形式で試しても崩れが続くこと、スレッドを変えても失敗パターンが引き継がれるように感じることなどを具体的に列挙。

「AIで画像を作るだけなら多少崩れていても使えるが、LINEスタンプは統一感・サイズ・文字の正確さが必要な『商品』であり、画像生成の延長では作れない」と結論。48時間かけて成果なしの状態を「失敗の記録」としてそのまま公開している。
