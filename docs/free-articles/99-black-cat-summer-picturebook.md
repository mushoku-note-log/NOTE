# 黒猫と夏の冒険

[← トップページへ戻る](../../README.md)

**種別**: 無料・制作記録（絵本制作ログ） | **公開日**: 2026年8月26日 | **原文**: https://note.com/mushoku_note_log/n/n7292993a8018

## 概要

Meta AIで少女と黒猫のキャラクターを固定し、実際に出した指示をそのまま公開する形式の絵本制作ログ。当初ラグドールを試したが猫が人形や別動物に見えてしまう等の試行錯誤の末、普通の黒猫へ変更してキャラクターを固定。「このキャラクターを固定してストーリー展開」という指示から、商店街の散歩・田んぼ道・縁側での月見・森・川・港祭り・灯台での星空観賞・帰宅までの1日を描く絵本が完成したと紹介している。

最初から絵本を作る目的で始めていないため、セリフ・キャプションはMeta AI自身が生成したものをそのまま採用。「最初に思い付きでも試してみないと出来ない。他人はまず完成形をイメージしてそれが出来上がらないと始めない。私は思いついたらAIに投げる、たったこれだけの違い」とまとめている。
