# 読まれない記事を、毎日書き続ける必要はあるのか？｜note収益化【58日目】

## 概要

58日目の報告。フォロワー940人、全体ビュー30,534、コメント111、スキ3,374。「毎日note日報を書く意味があるのか」という根本的な疑問を提示。書けることと読まれることは別で、「できました」系の日報はあまり読まれず、「売れなかった」系の記事にばかり反応が集まる状況を改めて指摘。

日報がPatreon・GitHubギャラリー・Pinterest等への導線になっているかも確認できておらず、日報を原稿にしていたフェイスレス動画も再生数3桁程度で収益化には遠いと説明。「続けることが正解とは限らない」とし、58日目にして日報を書き続ける理由そのものが弱くなってきたと結んでいる。
