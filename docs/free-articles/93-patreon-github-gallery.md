# Patreonの「中身が見えない」をGitHubギャラリーで補ってみた

[← トップページへ戻る](../../README.md)

**種別**: 無料・制作記録 | **公開日**: 2026年8月29日 | **原文**: https://note.com/mushoku_note_log/n/n3bc1252250f0

## 概要

Patreonで有料公開している作品が購入前の人にはほとんど見えないという課題に対応した制作記録。まずChatGPTのサイト作成機能で紹介サイトを作ったが1ページの簡易サイトにとどまり、作品数が増えるにつれもう少しまとまったギャラリーが必要と判断。Pinterest自動投稿用に整理していた「投稿済み」画像データ（高解像度版は削除済み、元画像のみ保持）をそのままWebギャラリーにも使えないかとCodexに相談し、GitHub Pages上にギャラリーサイト（mushoku-note-log.github.io）を構築したと報告。

2.5D・和風・水彩・立体造形・刺繍・クレイ粘土・水液体・蒸気煙霧・紙工芸・影絵発光ライン・盆栽・錦鯉など、多岐にわたる画風を一覧化。「販売用の高解像度データそのものは公開せず、雰囲気を確認してもらうためのギャラリー」と位置づけ、「一つ作ったデータを別用途に何度も展開する」という普段のAI活用スタイルの延長だとまとめている。ギャラリーを作っても「どう見つけてもらうか」という導線の課題は残ると結んでいる。
