# AIに相談してたら漫画ができました

[← トップページへ戻る](../../README.md)

**種別**: 無料・制作記録 | **公開日**: 2026年7月24日 | **原文**: https://note.com/mushoku_note_log/n/n16ba7a5b6375

## 概要

以前投稿したエレベーターのショートコメディ動画が約3万回、続く別の動画が約5万回再生されたが、YouTube収益は0円（収益化条件未達）、note売上も400円のまま変わらなかったという出来事を、ChatGPTに相談して短編漫画に仕立てた制作記録。似た動画を追加投稿しても再生数は2〜3桁に戻り、バズを再現するのは難しかったと振り返っている。

漫画では、再生数を見て一時的に「成功者気分」になった無職のおっさんが、最終的に収益0円の現実を突きつけられて謝る、という大げさな展開に脚色したと説明（掲載漫画そのものの図版・セリフ全文は本サイトには収録せず、note原文を参照）。過去のnote記事に残っている小さな失敗（Threads停止、売れなかった商品など）も同様に短編漫画化できそうだとし、現代版・江戸浪人版・白い猫のキャラクターシートを作成、ライトノベルを場面ごとに分割した長編漫画の制作も始めたと報告している。
