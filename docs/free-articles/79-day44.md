# 売れないから値下げする。その考えをやめました｜note収益化【44日目】

## 概要

44日目の報告。フォロワー824人、全体ビュー21,004、コメント86、スキ2,551。有料記事・BOOTH商品ともにこれまで売れたのは1件のみと報告しつつ、「売れないから値下げする」という発想をやめると宣言。「必要とされていないから売れないのであれば、価値がないと自分で判断して安売りする必要もない」と説明。

漫画制作で使っている「最低限のルールだけ決めて、あとはAIに考えてもらう」考え方は漫画以外にも応用できる核心的な方法であり、それこそ有料記事で扱っている内容だとして詳細は明かさないと述べる。AIの進化で個別の命令文は古くなっても「AIに何を理解させれば欲しいものに近づくか」という考え方の方が重要であり続けるとし、「売れない＝価値がないとは限らない。ただし自分が価値を感じる＝市場で売れるとも限らない。この二つは分けて考える」と結論づけている。
